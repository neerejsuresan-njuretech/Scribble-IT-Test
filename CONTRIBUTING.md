## Development Guidelines
- Use TypeScript and React 19 for frontend modules.
- Use Python 3.11 + FastAPI + SQLAlchemy 2.x for backend services.
- Adhere to strict role-based access control and RLS tenant isolation.
- Maintain responsive, accessible design across desktop, tablet, and mobile.
